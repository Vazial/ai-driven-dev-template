# .agents/ — Antigravity (Gemini) カスタマイズ領域

このディレクトリは、Antigravity (Gemini) エージェントの動作をカスタマイズするための専用ルートディレクトリです。

## 構成方針

当プロジェクト（ai-driven-dev-template）における運用原則として、**規程やエージェントの役割定義（SSOT）をこのディレクトリ内に再定義・複製することは避けてください**（P-04のドリフト防止原則）。

- 基本的なメタ規程は `meta/` 配下のドキュメント群を参照します。
- ツール固有のエージェント役割定義などについては、可能な限り `.claude/agents/` など既存の元本ファイルを参照する形をとります。
- `.agents/AGENTS.md` は、Antigravity起動時にそれらの元本へ正しく参照を向けるための「ポインタ・共通ルール」としてのみ機能します。
