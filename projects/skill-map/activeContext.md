## 外部の事実

connpass API v2 の一次情報は **`projects/connpass-session-radar/connpass-api-v2-facts.md`** が持つ。
本プロジェクトは再定義せず参照する。特に効くのは次の3点である。

- `GET /users/{nickname}/attended_events/` と `.../presenter_events/` は `start` と `count` しか
  受け取らない。**日付で絞れない**ので、期間を限るなら全件取ってから絞る
- 返るのはイベント検索と同じ完全なイベントオブジェクト（`hash_tag`・`group`・`lat`/`lon` を含む）
- 1秒1リクエスト・1回100件。履歴300件で約3秒
